# Meeting Minutes

All team meetings and team decisions are recorded in this folder by the Scrum Master.

## Index

| Date | Meeting | File |
|---|---|---|
| 2026-10-29 | Project Kickoff (Google Meet) | [2026-10-29-project-kickoff.md](2026-10-29-project-kickoff.md) |
| Sprint 1 | Online decision log (WhatsApp) | [sprint-1-decision-log.md](sprint-1-decision-log.md) |

## File Naming

- Meetings: `YYYY-MM-DD-<meeting-type>.md` (for example `2026-10-29-project-kickoff.md`)
- Decision logs: `sprint-<n>-decision-log.md`

## Required Content of Every Meeting Record

1. Date, time, and platform
2. Attendees and their roles
3. Discussed topics
4. Decisions
5. Action items with owner and status

Decisions that clarify a requirement must be recorded here before the shared documents are changed (see `CONTRIBUTING.md`, Section 12).
